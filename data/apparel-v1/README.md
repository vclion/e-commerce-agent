# 原创服装演示数据

山序男装与知织女装两家虚构店铺，各40款、400个SKU。全部商品、交易、规格、库存与竞品记录均为项目自编合成数据，没有真实用户信息。

字段、业务场景、来源说明和复现步骤见 [服装数据说明](../../docs/guides/服装数据说明.md)。记录数和基准日期见 `manifest.json`。金额字段 `*_fen` 为整数人民币分，尺寸单位为厘米；JSONL每行一条UTF-8 JSON。

这些文件仅导出明确列出的业务字段，不包含用户表、登录口令、会话Token或模型Key。重新导出命令：`.venv/bin/python -m scripts.export_apparel`。
