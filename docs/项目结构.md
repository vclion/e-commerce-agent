# 项目结构与开发约定

前后端以独立目录和依赖声明组织；根目录负责本地编排、集成脚本和共享资源。

| 目录或文件 | 职责 |
| --- | --- |
| `frontend/` | Vue 页面、样式、前端 API 客户端、npm 依赖和构建配置 |
| `backend/commerce/` | FastAPI 接口、业务规则、鉴权、数据库模型、知识访问和数据生成 |
| `backend/tests/` | 后端测试，使用独立 PostgreSQL schema |
| `backend/pyproject.toml` | 后端 Python 包和运行依赖 |
| `scripts/` | 项目启动、初始化、数据导出、知识库升级和 Dify 管理 |
| `tests/` | `unit/` 存放离线测试，`scripts/` 存放手动验收入口，`artifacts/` 存放本地产物 |
| `contracts/` | 业务服务对 Dify 暴露的工具接口契约 |
| `dify/` | 应用与工作流 DSL，以及当前工作空间的映射锁文件 |
| `knowledge/` | 公共、内部知识资料及清单 |
| `data/` | 可复用的演示数据导出 |
| `docs/` | [文档导航](README.md)；按使用、设计、验收、调研分类，已替代材料集中在 `archive/` |
| `vendor/` | 固定版本的外部 Dify 源码与其运行目录，Git 忽略 |
| `.runtime/` | 私有凭据、进程、日志、本地 Node 和备份，Git 忽略 |
| `pyproject.toml`、`uv.lock` | Python 工作区、集成脚本依赖、开发工具和统一版本锁 |
| `compose.yaml`、`.env` | 本地业务数据库编排和私有配置 |

## 开发入口

- 完整演示：在根目录执行 `bash scripts/dev.sh`，访问 `http://localhost:8000`。
- API 热更新：在根目录执行 `uv run uvicorn commerce.main:app --host 0.0.0.0 --port 8000 --reload --reload-dir backend/commerce`。
- 前端热更新：将项目内 Node 加入 PATH 后，在根目录执行 `npm --prefix frontend run dev`，访问 `http://localhost:5173`。
- 后端测试：在根目录执行 `uv run pytest -q`。
- 前端检查与构建：执行 `npm --prefix frontend run build`。

API 热更新与演示服务共用 8000 端口。切换前执行 `.venv/bin/python scripts/start.py --stop`；恢复演示服务执行 `.venv/bin/python scripts/start.py --restart`。

## 依赖和文件归属

后端运行依赖添加到 `backend/pyproject.toml`，根目录只声明工作区后端包、集成脚本依赖和开发工具。修改 Python 依赖后，在根目录执行 `uv lock` 和 `uv sync --frozen`。前端依赖在 `frontend/` 下使用 npm 管理，并同步更新 `package-lock.json`。

页面和浏览器逻辑放入 `frontend/src/`；接口与业务逻辑放入 `backend/commerce/`，对应测试放入 `backend/tests/`；离线数据测试放入 `tests/unit/`；跨服务的初始化放入 `scripts/`，手动验收放入 `tests/scripts/`。知识原文、数据导出和 Dify DSL 使用各自的共享目录。

开发时浏览器通过 Vite 的 `/api` 代理访问后端，无需在页面中保存后端地址或服务凭据。演示时由 FastAPI 提供 `frontend/dist/` 静态文件。后端保留 `/api` 和 `/tools` 两组接口，Dify 服务地址和接口契约继续在根目录配置。

## 本地产物与清理约定

测试产物统一保存在被 Git 忽略的 `tests/artifacts/`：通用报告在 `reports/`，截图在 `screenshots/`，数据压缩包在 `packages/`，离线数据校验在 `ops-data/`。运营修复、知识检索等专项沿用各自子目录；已被替代的报告集中在 `archive/2026-10-23/`，详见[测试目录说明](../tests/README.md)。根目录不再保留第二套 `artifacts/`。

私有配置、进程 PID、当前日志和媒体保留在 `.runtime/`；历史一次性维护脚本与安装日志放在 `.runtime/archive/`；数据库及迁移回退文件放在 `.runtime/backups/`。不要整目录删除 `.runtime/` 或 `vendor/`，其中包含现用凭据、素材及 Dify 数据卷。

Python 字节码和测试缓存可以清理。`.venv/`、`frontend/node_modules/`、已解压的 Node 和 `frontend/dist/` 是现用环境与演示入口，应保留。记忆 Embedding 当前只调用配置的 API，旧本地模型与专用环境已于 2026-10-21 清理；重新下载任何模型、依赖或数据前须获得用户明确允许。
