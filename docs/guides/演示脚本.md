# 运营 Agent 演示

打开 `http://localhost:8000`，使用运营账号 `operator` 和本机 `.runtime/本地访问信息.md` 中的密码。

1. 进入经营概览，查看全部授权店铺的成交、退款与分店对比；选择单店，核对统计口径与退款原因。
2. 打开商品资料，按品类、售价、尺码、面料筛选；比较两款商品，说明这些事实可以用于内容生成。
3. 打开店铺订单，核查当前店铺最近30条记录及售后状态；页面不提供售后申请或商品上架。
4. 打开选品研究，查看分项评分和资料不足候选；评分来自业务规则，不能宣称预测爆款。
5. 向运营 Agent 提问：“查询MEN-001-01-M的商品资料，生成两版有依据的短视频口播，不编造优惠。”选择保存类型“营销文案”，保存后在文案与报告中查看。
6. 提问：“分析最近7个完整自然日的成交和退款，区分事实、待验证原因和建议。”核对金额后保存经营报告。
7. 刷新页面，验证对话恢复；切换店铺，验证历史和查询范围随之变化。

模型尚未配置时可以演示查询和经营面板；真实对话需先在Dify配置DeepSeek并执行 `scripts.activate_dify`。

Dify当前使用1个运营Chatflow和4个Workflow：商品筛选、营销文案、选品研究、经营分析。消费者与商家旧应用已停用。

新增运营数据包位于 `data/douyin-ops-v1/`，包含18个后续验收场景。报表导入、视频指标、SOP与剪辑工具尚未接入，演示时不能将数据包中的预期结果当作工具运行结果。
