# 短视频网址解析接口（预留）

2026-10-17。先固定请求和返回结构，实际解析由后续提供的专用工具执行。当前默认实现不访问网址、不下载视频、不运行语音识别；返回HTTP 501明确表示工具尚未接入。此接口不依赖Dify或模型生成内容。

## 请求

`POST /api/ops/videos/parse`

使用现有运营登录令牌：`Authorization: Bearer <token>`。如指定 `X-Shop-ID`，请求店铺必须与当前选择范围一致。

```json
{
  "shop_id": "a",
  "url": "https://v.douyin.com/example/"
}
```

`url`接受HTTP/HTTPS视频页面网址或分享短链接；传单独网址，不传整段分享文案。具体平台与短链接支持范围由后续解析工具决定。

当前默认返回HTTP 501：

```json
{
  "code": "video_parser_not_configured",
  "detail": "视频解析工具尚未接入，当前不能解析视频或提取字幕；接口已预留。"
}
```

## 工具接入后的返回契约

以下只是HTTP 200结构示例，不代表当前已经解析该网址：

```json
{
  "shop_id": "a",
  "source_url": "https://v.douyin.com/example/",
  "resolved_url": "https://www.douyin.com/video/example-id",
  "parser": "supplied-video-tool",
  "video": {
    "platform": "douyin",
    "video_id": "example-id",
    "title": "示例视频标题",
    "author": "示例作者",
    "duration_seconds": 4,
    "media_url": null,
    "cover_url": null
  },
  "caption": "视频发布时的描述文案",
  "transcript": "示例第一句。示例第二句。",
  "transcript_source": "platform_subtitles",
  "subtitles": [
    {"start_seconds": 0, "end_seconds": 2, "text": "示例第一句。"},
    {"start_seconds": 2, "end_seconds": 4, "text": "示例第二句。"}
  ],
  "warnings": []
}
```

- `caption`是发布描述，`transcript`是视频字幕或口播转写，两者独立。
- `transcript_source`支持`platform_subtitles`（平台字幕）、`asr`（工具语音转写）、`provided`（提供的字幕）；来源未知时为`null`。
- 未获取的字段返回`null`，不能补造字幕或完播/成交等后台数据。未获取字幕为`subtitles: null`，工具确认没有字幕才可返回空数组。
- 字幕时间单位为秒，结束时间必须晚于开始时间；已知视频时长时，字幕不得超出时长。
- `media_url`只是工具返回的媒体地址，可能过期；不表示视频已下载或进入素材库。接口不自动创建同行记录或调用模型分析。

## 工具适配位置

代码：`backend/commerce/video_parser.py`。

实现`VideoParser`协议并让`get_video_parser()`返回适配器：

```python
class SuppliedVideoParser:
    name = 'supplied-video-tool'

    async def parse(self, url: str, *, shop_id: str) -> VideoParseContent:
        raw = await supplied_tool.parse(url=url)
        return map_tool_output(raw)  # 映射为VideoParseContent，保留真实来源与缺失值
```

HTTP、MCP或本地工具均可在这一层适配；令牌与服务地址留在后端配置，调用方请求结构不变。适配器应使用异步调用，阻塞工具需转入线程，确保60秒超时可生效。没有工具成功结果时，不以LLM或测试数据代替。

后续需要模型拆解时，可将真实`transcript`录入现有`POST /api/ops/peers`，再调用`POST /api/ops/peers/{reference_id}/analyze`。解析、保存和模型分析目前是独立操作。

## 状态码

| HTTP | 含义 |
| --- | --- |
| 200 | 工具返回且通过校验的视频信息/文案/字幕；具体缺失项仍为null |
| 400 | `video_url_unsupported`，工具不支持此网址 |
| 401 / 403 | 未登录或超出授权店铺范围；不会调用解析工具 |
| 422 | 请求字段或网址格式无效 |
| 501 | `video_parser_not_configured`，工具未接入 |
| 502 | `video_parse_failed`，工具失败、空结果或返回格式无效 |
| 504 | `video_parse_timeout`，超过60秒 |

OpenAPI与在线调试：[业务接口文档](http://localhost:8000/docs)。适配器成功分支使用独立测试替身验证，不作为实际工具已接入的证明。
