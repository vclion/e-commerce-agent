# 栏目会话与现有功能的聊天入口

2026-10-20。实现范围是左侧现有运营功能的聊天入口及栏目会话隔离。退款/售后执行、商品上架和外部发布不加入。

## 使用方式

切换左侧栏目，右侧助手随之切换到该栏目的历史、输入草稿、推荐问题和模型会话。切回来可接着问；刷新后恢复当前栏目及其已保存聊天。原先混合在一起的历史保留在“旧版总对话”，只供查阅，不混入新栏目上下文。

业务数据仍按授权店铺共享。例如全店分析可以读取任务和商品作为证据，但默认不会得到短视频栏目的聊天正文。聊天写操作按栏目限制；需要在其他栏目执行的操作会提示切换。

| 栏目 | 可通过聊天完成的主要工作 |
| --- | --- |
| 今日工作 | 查询/生成SOP、更新任务与证据、查看日报、设置自动生成时间、保存报告 |
| 全店分析 | 查询经营指标、覆盖缺口、库存与履约风险、对比店铺、保存分析报告 |
| 短视频运营 | 查询素材/指标/脚本/剪辑状态、保存同行参考、完整同行分析、生成并保存脚本、检查文案、生成改写候选、采用后保存、发起剪辑、重试失败任务 |
| 数据导入 | 查看字段与样例、检查文本报表、字段映射、校验预览、读取页面生成的批次、提交合法批次、保存映射模板、明确要求时加载合成测试数据 |
| 平台接入 | 查看配置缺失项和同步状态、检查已配置连接、排队同步、调整同步计划、明确要求时断开连接、补录有依据的本地商品事实 |
| 商品资料 | 筛选、查询与对比商品，补录已同步商品的本地事实；不修改平台价格、库存或上下架 |
| 店铺订单 | 查询订单、售后记录和履约风险；仅分析退款记录 |
| 选品研究 | 查询选品规则评分与竞品、保存用户提供的竞品快照、保存研究报告 |
| 文案与报告 | 查询本人草稿，生成有商品事实依据的内容，实际保存文案或报告 |
| 运行记录 | 查询本人业务/工具审计、按状态查看各栏目的运行摘要；摘要不包含其他栏目聊天正文 |

文件选择、视频素材上传、Excel/大文件上传、平台新建配置、凭据填写、OAuth授权继续使用现有页面表单。聊天面板提供返回这些表单的入口，不要求把密钥或文件编码粘进聊天。报表页面校验后，可在聊天中继续读取并提交对应批次。视频网址解析仍取决于原适配器配置，未配置时仍不可用。

“已执行的操作”由后端成功的工具审计生成，与模型的答复正文分开保存。改写只标记为候选，排队只标记提交请求，不能据此声称已剪辑或同步完成。失败的整轮回复也保留此前已经实际完成的操作，避免重试时误判。

## 实现与边界

- 会话绑定账号、店铺、数据来源范围指纹、栏目；`ChatRun`、`Conversation`、工具令牌均携带栏目。恢复会话时同时验证这些条件。
- `/api/chat`、`/api/chat/runs`、`/api/chat/conversations` 接收固定枚举 `workspace`；省略时为兼容旧客户端的 `general`，新前端始终传入当前栏目。
- 旧记录迁移为 `general`，重复初始化不会重分配或删除历史。
- 前端以账号、店铺、栏目保存独立状态。流式回调绑定发起请求的状态对象，切换栏目后仍写回原栏目。一次只生成一条回复；生成中可浏览其他栏目，等待完成再发送下一条。
- 聊天适配器复用页面的字段校验、店铺授权、版本冲突、导入去重和剪辑状态校验。不提供任意HTTP调用或SQL执行工具。
- `workspace_context` 返回当前栏目及可用操作；只读工具不能执行新写操作。写权限由服务端工具令牌决定，模型参数不能更改栏目身份。
- 平台工具返回脱敏状态，不返回App Key、Secret、Token或OAuth参数；正式店铺不能通过聊天加载演示数据。
- 运行记录跨栏目查询只在“运行记录”中提供摘要。普通栏目不能通过运行查询接口获取其他栏目的正文或运行摘要。

关键文件：`backend/commerce/chat_workspaces.py`（栏目/操作契约）、`workspace_tools.py`（页面适配器）、`main.py`（会话与执行结果）、`frontend/src/App.vue`（独立状态）、`scripts/generate_dify.py`（模型工具和栏目上下文）。

## 验证

后端：`backend/tests/test_workspace_chat.py` 覆盖栏目、账号、店铺和来源范围的恢复边界，旧历史迁移，跨栏目写入拒绝，报表预览/提交去重，以及草稿和定时计划的实际页面效果。

浏览器：`tests/tests/scripts/browser_workspace_chat_smoke.py` 使用临时账号，检查十个栏目、刷新/店铺切换、旧版历史、未发送输入、流式切换、移动端和真实模型调用。流式切换采用浏览器延迟响应模拟；真实模型验证报告保存、同栏目追问、素材查询，并核对后端工具记录及页面结果。临时账号及其草稿/会话/审计在结束后删除。

验证报告见 `tests/artifacts/reports/workspace-chat-browser-report.json`。本轮不使用真实抖店/抖音写接口，离线权限和模拟数据验证不能代替真实平台验收。

2026-10-20最终验证：109项后端回归通过（含14项栏目聊天专项），TypeScript/Vite构建通过；栏目聊天浏览器12项、原运营页面12项、平台离线浏览器8项通过，均无JavaScript错误。最终聊天浏览器验收包含3次真实模型请求，验证草稿实际保存、同栏目追问和素材工具调用。7个本地Dify应用已更新，公开文件凭据扫描通过，临时栏目验收账号已清理。

浏览器原回归适配了刷新保留栏目；选品按当次接口结果核对，有完整候选时检查评分列表，资料不足时检查缺失项并确认不提供分数，不通过补造数据使页面出现候选。真实模型验证属于抽样联调，不是全业务质量基准。
