# 抖店运营 Agent 实现与验收

2026-10-17更新。当前工作流为“导入 → 分析 → SOP → 内容生成 → 实际剪辑”。按需求移除“问题跟进”和“效果复盘”的页面、接口、Agent工具、问题导入和发布关联；每日任务不再依赖历史问题状态。历史记录保留归档，不提供操作入口。

## 直接测试

打开 http://localhost:8000，使用 `operator` 登录，密码见本机 `.runtime/本地访问信息.md`。双店测试数据已加载，服务已启动。

1. **今日工作**：查看所选日期双店任务，重复生成 SOP 不增加记录。点击“跟进任务”填写负责人、状态、进展和完成证据；阻塞需原因，完成需证据。可保存日报、设置每天几点生成。固定测试日期2026-10-16有16项任务。
2. **全店分析**：默认最近7个完整自然日，可切换30/60天和单店。测试数据截至2026-10-16 10:00（上海），7日两店支付443,315元、退款46,580元；山序支付118,246元、知织支付325,069元。净收款不等于利润；转化按买家日/访客日汇总。缺日期显示覆盖不足，当前或前期不完整时不输出环比。
3. **短视频运营**：查看60条账号视频指标、上传素材、录入同行字幕/转写。生成同行拆解后选择商品与参考，调用真实 DeepSeek 生成脚本。脚本可逐段修改素材、起止秒数和字幕，保存为新版本。点击“开始自动剪辑”，完成后预览/下载 MP4、封面和 SRT。测试素材和两条预置脚本已备好，可直接剪辑。
4. **数据导入**：可重复加载完整合成数据，或上传项目字段契约的 CSV、JSON、JSONL。先预览类型、必填字段、金额、日期、范围与重复冲突，再提交；提交时重新检查商品/视频/订单关联。批次和明细去重，旧来源时间不覆盖更新来源。下载字段示例可查看表头。Excel目前为查看版，不直接上传。

可以直接给 Agent 发出：

- “用已导入报表分析最近7天两家店的数据，列出优先处理的问题。”
- “生成今天的SOP，保留已有进度。”
- “读取 TEST-SCRIPT-a 当前版本并创建剪辑任务，告诉我任务ID。”
- “查询剪辑任务，告诉我哪些已成功、哪些需要处理。”

数据导入后，店铺订单与售后优先读取导入记录；商品资料、选品研究仍保留原有服装资料和竞品快照。经营分析不混合两套订单来源。

## 技术落点与运行

- `ops_data.py`：标准化导入、批次与来源、确定性统计、增量/累计口径。
- `ops_work.py`：SOP、证据与日报。
- `ops_media.py`：素材校验、DeepSeek Workflow、脚本版本、FFmpeg成片。
- `ops_worker.py`：定时任务、持久化剪辑队列、重启恢复。
- `ops_api.py` / `ops_tools.py`：同一业务逻辑供页面及Agent使用，授权范围在服务端检查。
- `frontend/src/OpsWorkspace.vue`：四个运营页面；`contracts/`：运营读写工具；`dify/workflows/`：六个Workflow。

本地服务默认 `OPS_WORKER_ENABLED=true`，在服务运行期间按上海时区执行计划。重启会将中断的剪辑重新排队，保留任务、导入批次、脚本版本和产物。当前部署按单API/worker进程设计，不能直接用多个Uvicorn worker运行；后续多实例部署需独立worker与租约机制。

需要本机可用的 FFmpeg/ffprobe、H.264/AAC编码与中文字幕字体。已在当前WSL验证；输出360×640、24fps竖屏，原音轨统一编码，无音轨填充静音。字幕烧录并单独输出SRT；当前不生成配音、不替换背景音乐。

## 当前能力边界

所有业务记录是合成测试数据。数据截至时间来自导入源；定时SOP不代表自动读取抖音后台。首版仅支持约定表头，真实平台导出需做字段适配，尚未接入开放平台API和自动发布。

同行拆解以提供的字幕/转写为内容依据，视频处理实测时长与场景切换；没有自动语音识别或语义画面理解。占位动画与提示音用于检验剪辑链路，不能代表真实服装实拍、真人口播或商业成片审美质量。真实模型调用失败会显示错误，不返回伪造的成功结果。
